# IMS 系统 ER 图

本目录包含 IMS 系统的分层 ER 图设计，按照高内聚、低耦合原则将 272 个实体划分为 10 个核心业务域。

## 目录结构

| 文件 | 模块 | 说明 |
|------|------|------|
| [01_主数据域_MD.md](01_主数据域_MD.md) | MD | 物料、客户、供应商、工艺、设备等基础数据 |
| [02_订单管理域_OM.md](02_订单管理域_OM.md) | OM | 销售订单、生产订单全生命周期管理 |

## 业务流向

```
客户下单 → 销售订单 → 生产订单 → 生产计划 → 排产 → 领料/报工 → 入库 → 发货
                ↓              ↓           ↓          ↓
            质检计划        采购申请      原料拣配    包装任务
                ↓              ↓           ↓          ↓
            来料检验        采购订单      合泥配料    外协发货
```

## 图例说明

- **实线** (`||--|{`, `||--o{`)：模块内部实体关系
- **虚线** (`~~~`)：跨模块关联（外部引用）
- **聚合根**：每个模块的核心实体，通常带有 `PK` 标记
